2. English को सुधारें

कोई Paid API इस्तेमाल नहीं होगा। Offline सफाई यहाँ होगी; असली AI Rewrite के लिए आपका ChatGPT खुलेगा।

⚡ Free Instant Demo — बिना API

आपने जो “Main Thoda late nikalunga” वाला टेस्ट किया था, उसके लिए चार तैयार translations का Demo। दूसरी पंक्तियों का AI अनुवाद नहीं होता।

Fast workflow: Demo के बाहर, कोई भी नया Hindi/Gujarati/Hinglish मैसेज English में बदलने के लिए ChatGPT का उपयोग करना होगा। AI इस्तेमाल करने का तरीका: Copy AI Prompt → Open ChatGPT → वहाँ Paste करके भेजें → English Result Copy करें → वापस यहाँ Paste AI Result दबाएँ। यह दो ऐपों के बीच मैन्युअल प्रक्रिया है।

3. जहाँ चाहें भेजें

Copy करके WhatsApp, Instagram, Gmail या किसी भी Text Field में Paste करें। iPhone Share Sheet भी आज़मा सकते हैं।

Clipboard और Share की सुविधा browser/security settings पर निर्भर हो सकती है। WhatsApp नहीं खुलने पर Copy करके Paste करें।
🔧 iPhone पर Voice Dictation कैसे चालू करें?
  1. Settings → General → Keyboard में जाएँ।
  2. Enable Dictation चालू करें।
  3. Settings → General → Keyboard → Keyboards से Hindi/English Keyboard जोड़ सकते हैं।
  4. इस ऐप के Original Message बॉक्स में टैप करके Apple Keyboard का माइक्रोफोन दबाएँ।

Language chips सिर्फ Web Mic की भाषा चुनते हैं; ये Apple Keyboard का Dictation language अपने-आप नहीं बदलते।

🔐 Privacy और Limitations

यह पेज कोई account, analytics, server या paid API नहीं जोड़ता। Draft Draft Save का विकल्प default OFF है; ON करने पर केवल इसी Browser में localStorage में सेव होता है। डिवाइस की Dictation Apple की processing पर निर्भर है; AI Prompt ChatGPT में आप स्वयं paste करते हैं। Web Mic चलने पर browser की speech service का उपयोग हो सकता है। इस prototype में system-wide iOS keyboard extension नहीं है।

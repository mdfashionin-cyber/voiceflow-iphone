पहले से चुने हुए कुछ टेस्ट वाक्यों के लिए Offline Example। यह कोई AI Translation Engine नहीं है। अलग वाक्यों के लिए Shortcuts या ChatGPT चुनें।

पहले iPhone Shortcuts में “VoiceFlow English” नाम का Shortcut बनाना होगा। उपलब्ध AI model और आपकी सेटिंग्स पर निर्भर।

Fast workflow: Shortcuts तैयार है तो “Apple Shortcut से English” दबाएँ → Shortcut का AI उत्तर Clipboard में Copy होगा → VoiceFlow में लौटकर “English Result Paste” दबाएँ। यदि Shortcuts उपलब्ध नहीं है तो “Copy + Open ChatGPT” दबाएँ → वहाँ Paste और Send करें → उत्तर Copy करके यहाँ Paste करें।

3. जहाँ चाहें भेजें

Copy करके WhatsApp, Instagram, Gmail या किसी भी Text Field में Paste करें। iPhone Share Sheet भी आज़मा सकते हैं।

Clipboard और Share की सुविधा browser/security settings पर निर्भर हो सकती है। WhatsApp नहीं खुलने पर Copy करके Paste करें।
🔧 iPhone पर Voice Dictation कैसे चालू करें?
  1. Settings → General → Keyboard में जाएँ।
  2. Enable Dictation चालू करें।
  3. Settings → General → Keyboard → Keyboards से Hindi/English Keyboard जोड़ सकते हैं।
  4. इस ऐप के Original Message बॉक्स में टैप करके Apple Keyboard का माइक्रोफोन दबाएँ।

Language chips सिर्फ Web Mic की भाषा चुनते हैं; ये Apple Keyboard का Dictation language अपने-आप नहीं बदलते।

⚡ Apple Shortcuts सेटअप — सिर्फ एक बार
  1. iPhone की Shortcuts ऐप खोलें → + → नाम ठीक VoiceFlow English रखें।
  2. Add Action में Use Model खोजें। Apple Intelligence सक्षम हो तो On-Device model चुनें; जरूरत के अनुसार Cloud या ChatGPT Extension भी चुन सकते हैं।
  3. Use Model के Prompt/Input field में नीले variable से Shortcut Input डालें। हमारी ऐप पूरा English-Rewrite निर्देश इसी Input में भेजेगी।
  4. एक और Action Copy to Clipboard जोड़ें; इसमें Use Model के Response को चुनें। चाहें तो Show Result भी जोड़ें। Shortcut Save करें।
  5. VoiceFlow में अपनी बात लिखें → Apple Shortcut से English दबाएँ। iOS अनुमति पूछे तो स्वीकार करें। Shortcut चलने के बाद वापस VoiceFlow आकर English Result Paste दबाएँ।

सीमा: यह Native Keyboard नहीं है। Apple Intelligence सभी iPhone/भाषाओं में नहीं मिलता। किसी model को select करना और आवश्यक permissions देना आपके हाथ में है। Model गलत English भी बना सकता है—भेजने से पहले जाँचें।

🔐 Privacy और Limitations

यह पेज कोई account, analytics, server या paid API नहीं जोड़ता। Draft Draft Save का विकल्प default OFF है; ON करने पर केवल इसी Browser में localStorage में सेव होता है। डिवाइस की Dictation Apple की processing पर निर्भर है; AI Prompt तभी ChatGPT या iOS Shortcuts तक जाता है जब आप संबंधित बटन दबाते हैं। Web Mic चलने पर browser की speech service का उपयोग हो सकता है। Shortcuts में चुने गए Cloud/ChatGPT Model आपके टेक्स्ट को उनकी सेवा तक भेज सकते हैं। इस prototype में system-wide iOS keyboard extension नहीं है।
